# Seed supplier links

Every crop carries a `seed_sources` array, and the plan's planting summary turns
each crop name into a link to the chosen supplier's category page for it. The
dropdown in the form picks which supplier.

| supplier | crops covered | missing |
|---|---|---|
| [Johnny's Selected Seeds](https://www.johnnyseeds.com) | 50 / 50 | — |
| [Hoss Tools](https://growhoss.com) | 49 / 50 | strawberries |
| [Burpee](https://www.burpee.com) | 48 / 50 | butternut squash, winter squash |

Links go to a **category** page ("tomatoes"), not a variety, so there is
typically a choice of five to fifteen varieties behind each one. Nothing about
price or stock is known, and no affiliate relationship exists with any of the
three.

The arrays were generated by the scrapers in [`scripts/`](../scripts/) and are
committed as data. They are URLs on someone else's site, so they rot; a link
that 404s means re-running the scraper, not a bug in the planner.
